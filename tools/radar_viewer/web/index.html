How to read these views

The waveform is one chirp or the mean of the captured chirps. Each receiver supplies 512 complex samples per chirp.

Spectrum averages power over the captured chirps. The waterfall keeps the most recent displayed spectra.

Doppler explores changes within a frame, using the median chirp interval. Exported frames have gaps; the waterfall is indexed by displayed frame, not continuous time.

Range, velocity and angle need further calibration. Full-record FFTs may combine multiple ramp segments. Features are not yet identified targets.

Residual RMS measures chirp-to-chirp variation after removing the frame mean. It includes noise, drift and motion; it is not target SNR.
