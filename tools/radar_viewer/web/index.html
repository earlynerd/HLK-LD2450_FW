03 / Processing

Range bins: the device exports bins -40..+40 of a 512-point FFT per chirp (about 0.64 m per bin at the 240 MHz sweep). Older raw recordings are converted to the same bins on the host.

No background reference. Subtraction affects spectrum and Doppler.

How to read these views

Each chirp arrives as range bins: the device's 512-point FFT of that chirp, bins -40..+40, so time samples are not available. Spectrum averages power over the captured chirps. The waterfall keeps the most recent displayed spectra.

Doppler explores changes within a frame, using the median chirp interval. Exported frames have gaps; the waterfall is indexed by displayed frame, not continuous time.

Range, velocity and angle need further calibration. Features are not yet identified targets.

Residual RMS measures chirp-to-chirp variation within the exported bins after removing the frame mean. It includes noise, drift and motion; it is not target SNR.
